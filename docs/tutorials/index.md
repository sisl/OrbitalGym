# Tutorials

Five tutorials walk you from a fresh checkout to a working planner on
GPU. Each takes 5–30 minutes; each ends with a pointer to the next.

| # | Tutorial | Time |
|---|---|---|
| T1 | [First rollout (RT 2D)](t1-first-rollout.md) | ~5 min |
| T2 | [Build an RTN scenario](t2-rtn-scenario.md) | ~15 min |
| T3 | [Write an active-pursuer policy](t3-active-pursuer.md) | ~25 min |
| T4 | [Plan with short-horizon search](t4-short-horizon-search.md) | ~30 min |
| T5 | [Run on GPU / MPS](t5-acceleration.md) | ~15 min |

Every code block on these pages is a snippet pulled from a pytest test
in `tests/docs/` that runs in CI — what you read is what runs.

For a per-game entry point that links across tutorials, how-tos, and
the API reference, see [Game guides](../games/index.md).
